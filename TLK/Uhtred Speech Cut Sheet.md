## 0. Method and honesty notes

- **Anchor points are real.** The video ships a subtitle track whose cue starts are: 0:00, 0:06, 0:14, 0:21, 0:29, 0:37, 0:47, 0:55, 1:04, 1:12. Those ten boundaries are taken verbatim from the caption track and are trustworthy.
- **Intra-cue splits are estimates.** Most cues pack two or three sentences into one 6–10 s block. I divided each cue by word count, weighted for delivery pace, so a line's in/out point can drift roughly ±0.3–0.5 s. Nudge them in your editor against the waveform.
- **Caption errors corrected.** The subtitle track reads "raised the day" and "for days" — speech-recognition slips for "a Dane" and "for Danes". Restored below. Everything else follows the caption text.
- **Tail cue.** The final cue at 1:12 shows only the fragment "you", almost certainly a subtitle overlap or trailing card. Treated as a hold, not a line.
- **Wisdom sayings are editorial distillations, not dialogue.** They are my one-line abstracts of each beat. Do not caption them as quotes from the show.

### 5b. Batch split with ffmpeg

Save the timecodes once, then loop. This is the fast, stream-copy version — near-instant, but cuts snap to the nearest keyframe, so expect up to ~1 s of drift:

```bash
#!/usr/bin/env bash
set -euo pipefail

IN="input.mp4"
OUTDIR="cuts"
mkdir -p "$OUTDIR"

# "in|out|slug" — in/out in HH:MM:SS.mmm
MAP=(
"00:00:00.000|00:00:04.300|01_for-i-speak-to-you"
"00:00:04.300|00:00:06.000|02_your-gods-are-my-gods"
"00:00:06.000|00:00:09.300|03_born-a-saxon-raised-a-dane"
"00:00:09.300|00:00:11.100|04_for-years-that-divided-me"
"00:00:11.100|00:00:14.500|05_gods-have-led-us-all-here"
"00:00:14.500|00:00:18.000|06_offer-you-a-bargain"
"00:00:18.000|00:00:21.000|07_fight-now"
"00:00:21.000|00:00:23.000|08_for-me-and-northumbria"
"00:00:23.000|00:00:29.000|09_saxons-and-danes"
"00:00:29.000|00:00:34.300|10_live-in-peace-here"
"00:00:34.300|00:00:37.000|11_i-swear-this-to-you"
"00:00:37.000|00:00:40.600|12_not-hunted-nor-forests"
"00:00:40.600|00:00:43.000|13_lands-and-homes"
"00:00:43.000|00:00:47.000|14_not-for-saxons"
"00:00:47.000|00:00:50.600|15_what-forebears-came-for"
"00:00:50.600|00:00:55.000|16_crossed-the-seas"
"00:00:55.000|00:00:57.600|17_to-make-a-homeland"
"00:00:57.600|00:01:01.400|18_follow-me-in-this"
"00:01:01.400|00:01:04.000|19_you-have-my-word"
"00:01:04.000|00:01:07.400|20_as-a-saxon"
"00:01:07.400|00:01:12.000|21_and-as-a-dane"
)

for row in "${MAP[@]}"; do
  IFS='|' read -r ss to slug <<< "$row"
  ffmpeg -hide_banner -loglevel error \
    -ss "$ss" -to "$to" -i "$IN" \
    -c copy "$OUTDIR/${slug}.mp4"
done
```

For frame-accurate cuts, re-encode instead — slower but exact:

```bash
ffmpeg -hide_banner -ss "$ss" -to "$to" -i "$IN" \
  -c:v libx264 -crf 18 -preset veryfast -c:a aac -b:a 192k \
  "$OUTDIR/${slug}.mp4"
```

Or make one file per line with the subtitle track burned in:

```bash
ffmpeg -hide_banner -ss "$ss" -to "$to" -i "$IN" \
  -vf "subtitles=uhtred_lines.srt" \
  -c:v libx264 -crf 18 -c:a copy "$OUTDIR/${slug}_subbed.mp4"
```
